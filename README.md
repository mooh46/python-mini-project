# Unit Converter

A Django web application that allows users to convert values between different units.

## Features

The application currently supports:

* Length conversion
* Weight conversion
* Temperature conversion

## Built With

* Python
* Django
* HTML
* CSS

## How to Run

1. Clone the repository.
2. Open the project in PyCharm.
3. Activate the virtual environment.
4. Run the Django development server:

```bash
python manage.py runserver
```

5. Open the local address provided by Django in your web browser.
